# Assignment #1 — HTML & CSS Basics

A practice project covering the fundamentals of HTML and CSS. It includes several tasks — from a personal profile page and layout with `<div>`s to a tribute page and a table/form styling exercise.

##  Project Structure

- `index.html`, `styles.css` — Task 1 (personal profile page) & Task 2 (div-based layout with header, navbar, sidebar, footer)
- `exercise1/index.html`, `exercise1/styles.css` — Task 3: Tribute page dedicated to Walter White
- `task4.html` — Task 4: styled data table (student grades) and feedback form
- `Sultanali.jpg` — image used in the Task 1 profile card

##  Features

- HTML structure: headings, lists, images, links
- CSS selectors: element, class, and ID selectors
- Layout using `<div>` and floats (no Flexbox/Grid)
- Table styling (`nth-child`, rowspan/colspan, ID selector)
- Form styling (input, select, radio buttons, textarea)
- Responsive and visually organized design
- Simple navbar linking between all task pages
